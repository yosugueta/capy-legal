# capy-legal

Public legal pages for the Capy app, hosted via GitHub Pages.

## Live URLs (after GitHub Pages is enabled)

- Landing: `https://yosugueta.github.io/capy-legal/`
- Privacy (EN): `https://yosugueta.github.io/capy-legal/privacy.html`
- Privacy (HE): `https://yosugueta.github.io/capy-legal/privacy-he.html`
- Terms (EN): `https://yosugueta.github.io/capy-legal/terms.html`
- Terms (HE): `https://yosugueta.github.io/capy-legal/terms-he.html`

Replace `yosigueta` with your actual GitHub username if different.

## How to publish (5 minutes, free)

1. Create a new **public** repository on GitHub called `capy-legal`.
2. Upload these 5 files: `index.html`, `privacy.html`, `privacy-he.html`, `terms.html`, `terms-he.html`.
3. Go to repo Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
4. Wait ~1 minute. GitHub will show the public URL.
5. Use that URL in App Store Connect under "Privacy Policy URL" and on your app's About screen.

## Editing later

Any edit to these files on `main` triggers a new deploy automatically. No build step.
